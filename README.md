# soundings

A lightweight scheduler for heterogeneous GPU/CPU workstations —
capability-aware leases with memory budgets, TTLs, and a fail-closed
launcher (the binary is `sounding`).

Status: the name is reserved on crates.io (v0.1.0); implementation
is in development. Releases publish via crates.io Trusted
Publishing (OpenID Connect) from this repository.
